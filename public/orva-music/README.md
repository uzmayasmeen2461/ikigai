ORVA reel music library
=======================

Place only licensed royalty-free music files in this folder.

Recommended sources:
- Pixabay Music
- Uppbeat
- Mixkit
- Free Music Archive
- YouTube Audio Library

Before adding a track, confirm that the license allows commercial/social video use.

How to add a track:
1. Download an MP3 or WAV file with a valid license.
2. Rename it with lowercase words and hyphens, for example `fashion-pop-01.mp3`.
3. Place it in this folder.
4. Add its metadata to `reelMusicLibrary` in `app/lib/reels.js`.
5. Test it in `/dashboard/reel-studio`.
